# CampusDesk Frontend Demo

A frontend-only student academic records demo. It runs in your browser and stores changes in that browser's `localStorage`. It does not connect to MongoDB, Atlas, a server API, or any external database.

## Open in VS Code

1. Open this folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and select **Open with Live Server**. It opens a local address such as `http://127.0.0.1:5500`.
4. Sign in with the demo credentials:
   - Email: `admin@campus.edu`
   - Password: `Campus123!`

You can also open `index.html` directly in a browser, though Live Server provides the localhost link.

## Screens

- Overview dashboard with sample academic totals
- Student directory: search, add, delete
- Courses: search, add, delete
- Enrollments: add, search, update grades/status, delete
- Demo user list and add-user form

Changes are stored only in the current browser. The records are fictional examples; this is a frontend demo, not a production authentication system.
